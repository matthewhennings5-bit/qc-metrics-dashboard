# QC Metrics Dashboard

Created by Matthew Hennings

## Overview

This project demonstrates how laboratory quality metrics can be tracked and visualized to support operational decision-making.

## Metrics Included

- Test Volume
- QC Failures
- Failure Rate
- Instrument Downtime
- Weekly Trends

## Purpose

The purpose of this project is to demonstrate the use of data analytics in laboratory operations and quality management.

## Future Enhancements

- Power BI Dashboard
- Automated Reporting
- Instrument Reliability Tracking
